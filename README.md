# Сервис создания каталогов коллекций

Консольное приложение для учёта личных коллекций. Владелец создаёт коллекции,
в каждой коллекции — разделы, а в разделах — предметы. Данные сохраняются
между запусками программы.

## Назначение и аудитория

Сервис помогает коллекционерам упорядочивать предметы, находить их по названию
и получать краткую статистику по коллекции.

## Сущности и формат данных

Данные представлены списками словарей и хранятся в каталоге `data/`:

- `owners.json`: владелец (`id`, `name`);
- `collections.json`: коллекция (`id`, `owner_id`, `name`);
- `sections.json`: раздел (`id`, `collection_id`, `name`);
- `items.json`: предмет (`id`, `section_id`, `name`, `condition`,
  `base_price`, `has_certificate`).

Идентификаторы связывают записи между собой. Например, `section_id` предмета
указывает на его раздел. При первом запуске пустые списки уже доступны в JSON;
если файл отсутствует, программа также считает соответствующий список пустым.

## Возможности ПР2

- просмотр каталога по владельцам, коллекциям и разделам;
- добавление владельцев, коллекций, разделов и предметов;
- удаление предмета, поиск по части названия и сортировка по алфавиту;
- подсчёт количества разделов и предметов и предварительной стоимости коллекции;
- обработка неверного числового ввода, отсутствующих связей и ошибок JSON;
- сохранён сценарий ПР1: оценка одного предмета с учётом состояния,
  сертификата и комиссии сервиса (пункт 10 меню).

В статистике предварительная стоимость каждого предмета рассчитывается
функциями исходного сценария ПР1. Классы и база данных на этапе ПР2 не используются.

## Структура проекта

- `main.py` — меню и вывод данных;
- `catalog.py` — операции с каталогом;
- `valuation.py` — расчёт стоимости и исходный сценарий ПР1;
- `storage.py` — чтение и запись JSON;
- `utils.py` — безопасный ввод чисел;
- `data/` — данные;
- `tests/` — тесты pytest.

## Запуск и проверка

Требуется Python 3.10 или новее. Для работы приложения сторонние библиотеки не
нужны. `requirements.txt` содержит инструменты проверки:

```bash
python -m pip install -r requirements.txt
python main.py
python -m pytest
python -m flake8
```

Для демонстрации начните с добавления владельца, затем коллекции и раздела;
после этого можно добавить предмет. ID созданной записи выводится после добавления.
