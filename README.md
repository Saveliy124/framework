# Сервис создания каталогов коллекций

Консольное приложение для владельцев коллекций. Владелец создаёт коллекции,
в коллекции — разделы, а в разделах хранит карточки предметов.

## Этап ПР1

Первый сценарий создавал карточку одного предмета без хранения данных.
Функции is_valid_year(), get_item_age() и get_card_status() проверяли год,
вычисляли возраст и сообщали, заполнена ли карточка. Этот этап сохранён
в истории Git отдельным коммитом 87bb851.

## Возможности ПР2

- просмотр каталога и отдельной карточки предмета;
- добавление владельца, коллекции, раздела и предмета;
- удаление предмета;
- поиск предметов по части названия и сортировка по алфавиту;
- подсчёт количества разделов и предметов в коллекции;
- загрузка и сохранение данных в JSON между запусками;
- обработка ошибок ввода, отсутствующих записей и повреждённых JSON-файлов.

Функции ПР1 перенесены в модуль items.py и используются при работе с карточками.
Данные представлены списками словарей. Классы и база данных пока не применяются.

## Сущности и данные

Файлы каталога data/ содержат списки записей:

- owners.json — владелец: id, name;
- collections.json — коллекция: id, owner_id, name;
- sections.json — раздел: id, collection_id, name;
- items.json — предмет: id, section_id, name, year, description.

Поля с суффиксом _id связывают записи. Год предмета проверяется при добавлении.
Описание можно оставить пустым: статус карточки покажет, что его нужно заполнить.

## Структура проекта

- main.py — меню и вывод;
- catalog.py — владельцы, коллекции, разделы и статистика;
- items.py — карточка предмета, добавление, удаление, поиск и сортировка;
- storage.py — загрузка и запись JSON;
- utils.py — ввод целых чисел;
- data/ — файлы данных;
- tests/ — тесты pytest.

## Запуск и проверка

Требуется Python 3.10 или новее. Приложение использует стандартную библиотеку.
pytest и flake8 нужны для проверки кода:

    python -m pip install -r requirements.txt
    python main.py
    python -m pytest
    python -m flake8

Начните с добавления владельца, затем коллекции и раздела. После этого можно
добавить предмет. Программа выводит ID каждой новой записи.
