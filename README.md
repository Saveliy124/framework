# Сервис оценки коллекционных предметов

## Назначение

Сервис помогает владельцу коллекционного предмета получить предварительную
оценку его стоимости, узнать размер комиссии за услугу и проверить готовность
документов для проведения экспертной оценки.

## Целевая аудитория

Пользователи сервиса - владельцы монет, марок, карточек, предметов искусства и
других коллекционных предметов. Также сервис предназначен для экспертов,
которые проводят оценку и оформляют результаты.

## Предметная область

Предметная область - предварительная и экспертная оценка коллекционных
предметов. Пользователь передаёт сведения о предмете, эксперт формирует оценку,
а по результату оформляется документ с итоговым заключением.

## Основные сущности

- **Предмет** - коллекционный объект, его название, состояние и базовая цена.
- **Эксперт** - специалист, который проверяет сведения и подтверждает оценку.
- **Оценка** - результат определения ориентировочной стоимости предмета.
- **Документ** - сертификат или заключение, подтверждающее сведения об оценке.

## Основные функции

- расчёт предварительной стоимости с учётом состояния предмета;
- расчёт комиссии сервиса за проведение оценки;
- проверка статуса документов для экспертной оценки;
- создание заявки на оценку;
- просмотр истории оценок;
- формирование экспертного заключения.

## План развития

На следующих этапах планируется:

- добавить хранение предметов и оценок в базе данных;
- реализовать личные кабинеты владельцев и экспертов;
- разработать веб-приложение на Django;
- добавить формы создания и изменения заявок;
- разработать REST API;
- подготовить контейнеризацию приложения и настройку CI/CD.

## Запуск

Требуется Python 3.10 или новее.

```bash
python main.py
```

Для запуска тестов:

```bash
python -m unittest
```
