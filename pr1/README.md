# Сервис создания каталогов коллекций

## Назначение

Приложение помогает владельцу упорядочивать предметы по коллекциям и разделам.
На этапе ПР1 реализован первый сценарий: создание и проверка карточки одного
предмета в консоли.

## Целевая аудитория

Коллекционеры, которые хотят хранить сведения о своих предметах в одном каталоге.

## Предметная область

Один владелец может вести несколько коллекций. Коллекция состоит из разделов,
а в каждом разделе находятся предметы с названием, годом и описанием.

## Основные сущности

- владелец — человек, ведущий каталог;
- коллекция — группа предметов владельца;
- раздел — часть коллекции;
- предмет — отдельная запись с названием, годом и описанием.

## Основные функции ПР1

- is_valid_year() проверяет год предмета;
- get_item_age() вычисляет возраст предмета;
- get_card_status() сообщает, заполнена ли карточка.

Начальный сценарий работает с одним предметом. Коллекции и циклы на этапе ПР1
ещё не используются; данные пока не сохраняются между запусками.

## Запуск

Требуется Python 3.10 или новее:

    python main.py

## План развития

В ПР2 данные будут представлены списками и словарями, код разделится на
модули, появятся добавление и поиск предметов, сохранение в JSON и тесты.
Позже планируются классы, Django, база данных, пользователи и API.
